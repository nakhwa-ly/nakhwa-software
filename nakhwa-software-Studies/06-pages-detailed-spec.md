# 06 — مواصفات الصفحات التفصيلية

> هذا المرجع الأهم أثناء البناء. كل قسم له مواصفات دقيقة لتجنب الاختيارات العشوائية.

---

## 🏠 الصفحة الرئيسية — `/`

### القسم 1: Hero Section

**الموقع:** أعلى الصفحة، بعد الـ Navbar مباشرة
**الارتفاع:** `min-h-[90vh]` على الديسكتوب، `min-h-[80vh]` على الموبايل
**الخلفية:** Gradient ناعم + عناصر متحركة (blobs أو particles)

**العناصر:**
```
┌──────────────────────────────────────────┐
│                                          │
│   [Badge صغير: "🚀 شريكك التقني"]       │
│                                          │
│   عنوان كبير (h1)                       │
│   "نخوة للحلول البرمجية"                │
│   ← مع gradient text للكلمة المميزة     │
│                                          │
│   وصف فرعي (text-xl, text-muted)        │
│   "نبني تطبيقات الجيل القادم..."        │
│                                          │
│   [زر أساسي: ابدأ مشروعك]               │
│   [زر ثانوي: تصفح أعمالنا]              │
│                                          │
│   ─── trust indicators ───              │
│   ⭐ 25+ مشروع   |   🌍 ليبيا والخليج    │
│                                          │
└──────────────────────────────────────────┘
```

**الأنيميشن:**
- العنوان: staggered word reveal (Framer Motion)
- الوصف: fade in بتأخير 0.3s
- الأزرار: fade in بتأخير 0.5s
- الخلفية: blobs متحركة ببطء (animation infinite)

### القسم 2: Services Section

**العنوان:** "خدماتنا" / "Our Services"
**Subtitle:** "حلول برمجية متكاملة لنمو أعمالك"
**Layout:** Grid 3 أعمدة على الديسكتوب، 2 على التابلت، 1 على الموبايل

**بطاقة الخدمة الواحدة:**
```
┌────────────────────────┐
│  [أيقونة كبيرة بلون]   │
│                        │
│  عنوان الخدمة          │
│  (text-xl, font-bold)  │
│                        │
│  وصف قصير (2-3 أسطر)   │
│                        │
│  [اقرأ المزيد →]       │
└────────────────────────┘
```

**الخدمات الـ 6 (icons من lucide-react):**

| # | الخدمة | الأيقونة | اللون |
|---|--------|---------|------|
| 1 | تطوير تطبيقات الموبايل | `Smartphone` | primary |
| 2 | تطوير المواقع الإلكترونية | `Globe` | primary |
| 3 | أنظمة إدارة الأعمال | `Briefcase` | accent |
| 4 | تكامل قواعد البيانات | `Database` | primary |
| 5 | تطبيقات التوصيل والمتاجر | `Truck` | accent |
| 6 | الاستشارات التقنية | `Lightbulb` | accent |

**Hover Effect:**
- البطاقة ترتفع (`translateY(-8px)`)
- الـ shadow يصبح أكبر
- الأيقونة تتحرك بحركة خفيفة
- Border يتحول للون primary

### القسم 5: Stats Section

**Layout:** 4 عدّادات في صف واحد، مع gradient background خفيف

```
┌──────────┬──────────┬──────────┬──────────┐
│   25+    │   15+    │   5+     │  1000+   │
│ مشروع    │  عميل    │  سنوات   │  فنجان   │
│  مكتمل   │  سعيد    │  خبرة    │  قهوة ☕ │
└──────────┴──────────┴──────────┴──────────┘
```

**الأنيميشن:**
- العدّاد يبدأ من 0 ويزداد عند الظهور في الشاشة
- استخدم `framer-motion` `useInView` للتفعيل
- Duration: 2 ثانية
